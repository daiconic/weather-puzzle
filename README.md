# Weather Lab — 風・水分・雨の試作

Bevy 0.20.1 / Rust 1.99.1 で作る、気圧配置を操作する2Dパズルの試作です。

## 起動

このディレクトリで `cargo run` を実行します。初回は依存ライブラリの取得とコンパイルに時間がかかります。開発時もゲーム本体を最適化レベル1、依存ライブラリをレベル3でビルドします。最適化設定を変更した直後も再コンパイルに時間がかかります。

## 操作と観察

- オレンジの **L（低気圧）** を左ドラッグすると移動します。
- 青い **H（高気圧）** は固定です。
- **Space** で再生・一時停止します。初期状態は停止中です。
- **M** で水分の色表示を切り替えます。
- **R** で気圧・水分・雨・累積降水量・時刻を初期状態へ戻して停止します。
- ウィンドウの閉じるボタンで終了します。

まずLを農地（FARM）の北から南へ動かし、農地付近の矢印がどう変わるか観察してください。位置以外のパラメータは変わりません。矢印の向きは風向、長さは風の強さを表します（表示上の上限あり）。

Spaceで再生すると、海から陸へ水色が広がります。水色が濃いほど水分が多い状態です。青い短い線は現在降っている雨です。停止中は雨の線もその時点で静止します。Mは水分の色だけを切り替え、雨は残します。画面上部に時刻、農地中心の水分量、農地全体の平均累積降水量、表示のON/OFFが出ます。水分量はゲーム内の0〜100%の指標で、温度を考慮した相対湿度ではありません。

比較する場合は、初期配置で30秒ほど再生した後にRで戻し、Lを南東へ動かして再び同じ時間まで進めてください。風と水分の通り道の違いを観察できます。停止中もLを動かせます。

## 今回の実装範囲

海・山・南側の通り道・農地を表示し、気圧配置から風のベクトルを計算します。入力は「各地点の座標、高気圧と低気圧の座標」、出力は「各地点の風の横・縦成分」です。

風は、高気圧から外へ向かう成分、低気圧へ向かう成分、弱い西風を足したゲーム用の場です。気圧中心で発散しないよう距離の式に定数を入れています。同心円は気圧中心の記号で、計算した等圧線ではありません。

水分は32×18マスの配列で保持し、1/30秒の固定刻みで更新します。風上の座標へ遡って前の時刻の値を補間する半ラグランジュ法で移流し、海では飽和へ向けて補給します。風の表示用ベクトルを75倍したワールド座標/秒を移流速度としています。領域外から入る空気は乾燥、外へ流れる空気は流出として扱います。この方式は数値拡散があり、水分の総量を厳密に保存しません。物理予報ではなく遊びを確かめるための濃度モデルです。

雨は風上の標高と現在地の標高の差から上昇量を求め、低気圧付近の上昇効果を加えて計算します。水分が0.25を超えた部分から、上昇が強いほど多くを雨へ変換します。雨になった分は空気の水分から減らし、地面の累積降水量へ加えます。累積雨量は地面に固定し、風では運びません。農地の累積値は黄色の農地範囲に入る6マスの平均で、ミリメートルではなくゲーム用の単位です。

地形は降雨に影響するようになりました。山による風向きの変化、独立した雲の状態、クリア判定はまだ実装していません。現実の大気の回転や気圧の時間発展も再現していません。

表示文字は内蔵フォントで動く英語表記です。

## コードの読み方

`src/main.rs` の `setup` は地図を作り、`drag_low` は入力を処理します。`wind_at` は風の計算だけを担い、`draw_weather` は結果を矢印で描きます。

`src/moisture.rs` は水分の状態・補間・移流を担います。`controls` が再生・停止とリセット、`transport` が固定刻みの更新、`show_moisture` が表示を担当します。

`cargo test -- --nocapture` は、風向の変化、気圧中心での数値安定性、水分の風下への移動、停止と海からの補給、低気圧配置による移流の変化と0〜1の範囲を検証します。同じ30秒の比較で、全576マスの水分量の平均絶対差は約0.1813でした（初期低気圧と座標350,-200の比較）。

API参照: https://bevy.org/examples/2d-rendering/rotate-to-cursor/ および https://bevy.org/examples/gizmos/2d-gizmos/

## 表示更新の負荷対策

水分の色は水分状態が変わったときだけ確認し、色が同じマスは書き換えません。停止中の固定更新では水分リソースを変更扱いにしません。状態の文字列は再生中に毎秒5回まで更新し、再生・停止・表示切り替え・リセットはすぐ反映します。文字が同じ場合は代入を省き、低気圧の座標も移動したときだけ書き換えます。

シミュレーションは毎秒30回のままです。風の線とウィンドウの描画は停止中も続きます。これは不要な更新を減らす変更であり、CPU/GPU使用率やフレーム時間の改善率はまだ測定していません。

停止状態で水分・色・文字が変更扱いにならず、停止中の表示切り替えが反映されることを追加テストで確認します。

## 雨を観察する

初期配置のままSpaceで再生すると、山の風上側などに青い雨の線が現れます。Rでリセットし、低気圧を農地の少し南（ワールド座標350,-100付近）に動かしてから再生すると、農地の雨量も増えます。テストで同じ60秒を比較した結果は、初期配置がほぼ0、南東配置が約0.0216ゲーム単位でした。これはクリア条件ではなく、配置による違いの確認です。

雨のテストでは、上り風で雨が降って水分が減ること、下り風や乾いた空気では雨が出ないこと、停止中に累積値が変わらずリセットでゼロになること、実際の地形と気圧配置で農地雨量に差が出ることを確認します。
